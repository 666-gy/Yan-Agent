# 测试使用方式

日常改动优先运行 `npm run test:smoke`：20 个测试文件覆盖 Core、会话保存与恢复、连接、附件、文件修改保护、Shell 权限、工作区隔离、运行编排、内核配置与资源、nested、插件、更新和语音输入。失败会原样返回，不自动跳过。

`npm run test:desktop` 启动真实 Electron，检查启动、会话 IPC、消息渲染和设置导航。它使用独立临时数据目录，不调用付费模型，不保存截图，退出后清理自己的数据。

`npm test` 仍运行全部现存的 `*.test.cjs` 单元及集成回归。此次没有把它改成小集合，也没有缩小 CI 的覆盖范围。

专用 `*.e2e.cjs` 按功能手动运行，例如 `node test/kernel-v2-desktop.e2e.cjs`。部分用例需要构建产物、本地服务、下载资源或真实 API，先阅读文件头；这些不是默认冒烟检查。打包链使用的 provider matrix、Playwright 验证入口保持不变。
