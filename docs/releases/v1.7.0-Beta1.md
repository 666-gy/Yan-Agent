# Yan Agent 1.7.0 Beta1 更新清单

对比基线：Git 正式版标签 `v1.6.0`。发布名称：`Yan Agent v1.7.0 Beta1`。源码版本：`1.7.0-beta.1`。本次仅构建 Windows x64 安装版。整理日期：2026-09-30（本机时间，UTC+08:00）。

清单依据当前工作区的实际代码、资源、测试和实现文档整理，包含尚未提交的新增文件。它描述 1.6.0 与当前开发内容之间的变化，不将已有测试文件视为本次全部通过，也不代表 Beta1 安装包已生成或公开上传。

## 1. 主界面与导航

- 重整桌面主界面，左侧固定导航栏统一进入聊天、扩展和设置。
- 扩展共用侧边栏，分为插件、智能体、技能和 MCP 四个页面；支持键盘切换、折叠、重新展开和窄窗口布局。
- 重做新聊天空白页、工作区选择与输入区域，统一图标、按钮、弹层、焦点及浅色／深色主题表现。
- 设置改为独立工作页面，加入常规、外观、壁纸、配置、个性化、Domml 与虚拟宠物、应用快照、浏览器、Git、Worktrees、模型配置、多模态及已归档聊天入口。
- 修正设置切换时侧栏、待办面板、右侧工具与焦点的显示关系，避免隐藏内容遮挡当前页面。
- 增加渲染器致命错误提示和启动恢复提示，启动异常不再只留下空白界面。

## 2. 聊天输入、消息与任务状态

- 输入框支持富文本输入、链接标签及加粗／斜体等编辑操作，改进粘贴、光标和选区处理。
- 插件、技能与桌面智能体可通过标签加入输入内容；示例可在当前工作区创建带草稿的新聊天。
- 扩展和技能示例不会自动发送任务，创建示例草稿时保留原聊天草稿。
- 输入框按内容增长并在六行后滚动，调整不同窗口宽度下的布局。
- 消息文本选择增加复制和添加到对话操作；改进用户消息拖动选取。
- 完善运行中追加输入：可选择排队或直接引导当前任务；直接引导通过当前内核送达。
- 修正撤回条件，只允许撤回用户主动停止后的适用末轮消息。
- 改进思考区标题、分段意图与摘要显示；摘要异步结果按原消息归属保存，异常不阻断主任务。
- 增加回复详略、思考摘要等配置的运行时传递；禁用摘要时不发起摘要请求。
- 修正任务状态、失败工具过程、长聊天滚动恢复及后台任务切换后的尾部呈现。

## 3. 聊天管理与深度链接

- 统一聊天右键菜单：重命名、置顶、已读／未读、归档、永久删除、复制及打开方式。
- 新增归档聊天管理页，支持查询、恢复和删除已归档聊天；运行中的聊天受保护。
- 新增 `yanagent://` 聊天深度链接，可复制链接、跨窗口打开，支持冷启动和应用已运行时的跳转。
- 聊天链接可作为任务引用进入输入和上下文，按真实会话读取内容，并限制引用预算。
- 支持复制聊天为 Markdown、导出 JSON，以及复制工作目录。
- 聊天删除同步清理关联内核会话，避免仅移除界面记录后残留内核历史。
- 增加会话数据格式迁移、尾部加载预算、运行记录裁剪和中断回合收尾。
- Blank 聊天可设置独立存储根目录；修改默认位置只影响新建目录，已有聊天继续使用原位置。

## 4. 插件系统

- 新增独立插件包系统，统一安装、配置、启用、停用、升级和卸载；插件可提供技能、资源及本地／远程 MCP 服务。
- 目录提供 Remotion、HyperFrames、Figma、Canva、Game Studio、CircleCI、Build iOS Apps 和 Build macOS Apps。
- 插件详情展示介绍、来源、版本、开发者、许可与服务链接、技能列表和使用示例。
- 插件总开关和单项技能开关持久化保存；关闭后从模型发现、资源读取和激活路径中撤销对应能力。
- 提供插件账号连接和断开流程；需授权的服务在系统浏览器完成登录与授权，再将状态反馈到 Yan。
- 在线安装固定上游版本并校验文件摘要；失败不会登记为安装成功，已校验缓存可用于重试。
- 部分插件仅随包提供目录元数据，由用户安装时取得上游工作流与许可；不将所有第三方内容直接再分发。
- 模型可列出、检查、激活、读取资源和停用插件；激活后注册服务实际返回的工具 schema。
- 插件工具使用会话独立命名空间，固定版本与配置，并在执行前再次检查归属、启用状态和权限。
- 去除开发演示包与本地文件夹导入入口；已有其他安装仍可管理。

## 5. Codex／Claude 桌面智能体协作

- 新增 Codex 和 Claude 智能体目录、详情、示例、启用开关、桌面程序检测及路径配置。
- Yan 可将任务派发到实际 Windows 桌面应用会话，通过桌面辅助功能输入，并只读监听对应本地日志回收结果。
- 首次派发创建新会话；同一工作区、同一提供商后续优先复用已核验的原桌面会话。
- 派发记录、输入全文、摘要校验、发送意图与回执持久化，重启后恢复监听，避免重复发送。
- 派发先核验唯一握手、会话身份及实际工作目录，再发送完整任务；不凭窗口标题或“最近聊天”猜测目标。
- 支持任务依赖和阶段编排，前置成功后附上结果交给后续任务，失败则阻断下游。
- 同一工作区及同一桌面提供商分别串行；不同工作区可由不同提供商协作处理。
- 等待支持游标和分页结果，单次等待结束不等于任务失败；不因等待较长重复派发。
- 保护外部应用已有草稿，不自动处理登录、目录信任或权限提示；发送后取消需要在目标应用确认停止。
- 新增 Windows 原生桌面桥编译与打包检查。真实 GUI 验证仍受外部应用版本、账号与登录状态影响。

## 6. 技能管理与 MCP

- 技能管理拆分来源、清单、标识、路径保护、图标和可用性策略，统一模型访问边界。
- 支持为项目指定其他 Agent 的技能文件夹，以目录链接或完整复制方式导入，并记住工作区来源。
- 技能来源显示项目归属；导入只管理 Yan 记录的条目，避免删除工作区内其他内容。
- 增加技能独立启停，父技能关闭时同步限制子技能；管理页仍保留可重新启用的条目。
- 增加技能详情与使用示例，示例进入新聊天草稿；插件、技能、MCP 页面统一完整列表展示。
- 新增 MCP Puller 工作流和 MCP 管理工具，支持核验来源、安装、配置以及读取实际连接状态。
- 延迟 MCP 在内核启动时保持未连接，任务需要时再激活；HTTP 请求成功不能单独视为 MCP 已连接。
- 改进远程 MCP、工具发现与运行上下文绑定，减少无关服务在每次启动时加载。
- 新增 Domml 创建技能，与媒体资产和虚拟宠物安装路径衔接。
- 清理停用技能与旧前端／动画技能副本，保留退役清单处理旧配置。

## 7. 模型连接与适配器

- 模型连接改为官方预设侧栏和统一表单，可直接编辑名称、Base URL、兼容预设、API 格式和密钥。
- 文本、图像、视频端点在同一连接面板分栏配置；增加保存、测试和失败状态反馈。
- 新增 ANTL、AGNL、GEML、GROL 适配路径，分别覆盖 Anthropic Messages、Agnes、Gemini 和 Grok 的请求处理。
- 统一适配器选择：显式预设优先；自动判断时优先识别当前模型家族，再参考连接名称和地址。
- 修复多厂商中转中连接名称误导模型适配器的问题；尊重用户显式选择的 Chat Completions／Responses／Messages。
- ANTL 增加稳定工具定义、显式缓存断点和缓存用量处理，不擅自改变用户选择的付费缓存时长。
- GPTL 与其他 Chat 适配器统一稳定工具排序、会话缓存亲和标识、usage 归一化及诊断字段。
- 保留中转返回的思考历史，Gemini 工具调用保留真实 thought signature，不伪造签名。
- 改进增量工具名、参数分片、累计参数快照、并行工具 ID 及完整 JSON 响应兼容。
- 已确认结束的流不再因上游 HTTP 长连接悬挂而一直等待；提前 EOF、截断或非法工具参数明确报错。
- 加强 UTF-8 分片、BOM、不同换行、多行 SSE data、event 类型和取消竞争处理。
- 仅对明确拒绝可选缓存 key／usage 参数且尚未产生输出的请求进行有限兼容重试。
- 修正带查询参数的完整端点拼接，移除不应进入实际请求的内部推理标记。
- 修复自定义连接的视频生成适配器选择；模型速度、缓存命中与线上能力仍以服务实际返回为准。

## 8. 内置浏览器与页面管理

- 新增浏览器设置页：公网／本地链接打开位置、Agent 可见性、完整 URL、下载目录、历史授权及站点工具开关。
- 增加可查询、删除和按时间范围清理的浏览历史，以及站点数据和缓存清理。
- 下载功能新增下载列表与弹出面板，展示进度、完成、失败和取消，支持配置保存目录及询问位置。
- 同站点不同标签页独立缩放，避免一个标签改变另一个标签的页面比例。
- 增加真实网页 PDF 导出，选择保存路径后生成 PDF；取消或目标页面变化时终止。
- 后台闲置标签可冻结页面并在切回时恢复，保留页面状态；当前页、Agent 页、表单编辑、媒体、下载和调试等状态受保护。
- 浏览历史等高频变动合并为异步原子写入，减少同步写盘阻塞。
- 主窗口位置、尺寸与最大化状态持久化；屏幕变化和异常坐标时修正可见区域。
- 主窗口隐藏时继续接收任务内容，恢复后显示完整进度；清理旧 3D 界面遗留 GPU 强制参数。
- 继续完善网页元素注释、Agent 标签暴露及权限绑定，避免页面或任务切换后操作错误目标。

## 9. 密码与通行密钥

- 新增浏览器密码管理器，支持保存、查看、修改、删除和网站登录填充。
- 密码使用系统加密存储；加密不可用时拒绝明文降级，列表只返回必要元数据。
- 增加密码提交、来源匹配和自动填充保护，跳转或上下文变化后失效旧请求。
- 支持网站主动发起的条件式通行密钥创建：近期匹配密码登录后先提示确认，再交给 Chromium 和系统认证器处理。
- 支持通行密钥多账号选择，取消、超时、导航和关闭页面均释放回调。
- 通行密钥由系统／认证器管理，Yan 不保存私钥；该流程依赖网站支持，不能为任意网站自动升级。

## 10. 图片查看、编辑与多模态

- 新增附件图片查看层及右侧图片编辑器，可缩放、调整显示并通过系统照片应用或资源管理器打开。
- 增加图片标注、文字编辑和评论，将用户选定位置与要求组织为明确的图片编辑上下文。
- 增加涂抹擦除区域，支持笔刷大小、撤销、重做、缩放下绘制及选区发送。
- 提供移除背景和调整大小的任务入口，与实际图像处理／模型服务衔接。
- 处理编辑切换、放弃更改、任务排队和草稿保留，避免重复发送评论或覆盖未发送内容。
- 加强媒体资产身份、路径和所属上下文校验，编辑操作围绕指定图片执行。

## 11. 应用快照

- 新增外部应用单帧快照，可选择窗口并将截图作为当前聊天的图片附件。
- 附件显示应用名称、图标与预览，支持悬停查看和移除。
- 支持双击 Alt 或双击 Shift 触发，并配置发送到当前聊天、新聊天或自动选择。
- 可配置快照提示音，处理窗口不可用和捕获失败状态。
- 快照沿正常附件通道发送；不是持续录屏，也不自动授权操作外部应用。

## 12. 外观、壁纸与通知

- 界面、正文和代码字体可分别选择本机字体及字重，调整界面／代码字号、对比度与强调色。
- 增加独立外观控件与字体加载样式，设置持久化并应用到相关界面。
- 仅内置「夜空-天体-天空」图片和「下雨天-中式建筑」视频两款壁纸；支持自定义上传、MP4 静音播放、视频预览及界面材质适配。
- 优化壁纸下的聊天、侧栏、审阅和设置层级，减少重复叠色及文字对比问题。
- 常规设置增加上下文占用显示、快捷审阅、思考展开、追加消息方式及独立快捷聊天选项。
- 可配置任务完成、审批请求、提问通知和默认／单铃／双铃／静音提示。
- 文件默认打开方式支持资源管理器、VS Code 或终端；终端可选 Git Bash、PowerShell、Windows PowerShell 和 CMD。
- 改进 Windows VS Code 检测，增加注册表查找及具体文件打开支持。

## 13. 个性化、记忆与虚拟宠物

- 新增个性化设置页，集中管理记忆开关、自定义指令及记忆删除。
- 记忆开关进入运行上下文，关闭后停止相应记忆写入和任务后的记忆整理。
- 自定义指令或记忆设置变化时隔离旧内核会话，避免继续沿用过期系统上下文。
- 删除记忆覆盖全局和已知工作区；运行或整理期间禁止竞争删除，并保留删除保护。
- Domml 与虚拟宠物设置集中展示内置宠物和用户创建宠物，支持选择、预览与删除自定义项。
- 新增 PNG 静态／精灵图宠物存储和安装校验，可使用生成图片资产制作宠物。
- 调整宠物窗口与渲染行为，清理旧宠物资源。

## 14. Git、PR 与托管 Worktrees

- 新增 Git 偏好设置：分支前缀、合并方式、受保护强推、草稿 PR、审阅方式及提交／PR 文案指令。
- 提供 PR 监控工作流偏好和自定义指令；是否合并遵循用户明确授权及设置。
- 改进实际 Git／GitHub 调用和提交／PR 界面，偏好进入运行上下文，不只保存在表单。
- 新增托管 Worktrees 设置，可选根目录、创建前 fetch、自动清理及保留数量。
- 维护活动与归档工作树登记；归档保存 Git 恢复快照，可恢复跟踪文件和未忽略的未跟踪文件。
- 自动清理保护脏工作区、忽略文件、嵌套仓库、锁定、置顶及使用中的工作树。
- 修改工作树根目录仅影响新建位置，旧登记仍可发现、恢复和使用。
- 修复路径规范化、重命名差异、文件打开和 PR 操作中的兼容性问题。

## 15. 审阅与代码展示

- 更新 dsh 审阅组件与相关依赖，改进文件差异、文件树、展开折叠、图片和批注交互。
- 新增更完整的 Markdown、GFM、数学公式和代码高亮依赖与构建链。
- 修正实际生产数据形状、审阅区域滚动、侧栏布局及壁纸主题适配。
- 快捷审阅显示与审阅任务路由可按偏好配置，保留真实文件变化与验证结果的关联。

## 16. 权限与运行边界

- 新增 Agent 沙盒、Shell 权限守卫、原生 Bash 工具衔接及权限审计记录。
- Shell 授权记忆按有限命令前缀组织，复合命令、危险根命令和动态表达式不生成宽泛可复用授权。
- 增加文件观察门控，在适用工具链中检查修改目标是否有当前上下文的读取依据。
- 加强工作区、Blank 目录、会话、插件工具与 MCP 运行上下文之间的归属隔离。
- 敏感 IPC 校验主窗口和主框架来源；任务深度链接只接受规定的会话路由。
- 文件、插件、技能及媒体处理加强真实路径、链接、目录穿越、类型和大小检查。
- 这些应用层检查不等同于操作系统级容器或外部应用的权限授权。

## 17. 内核、持久化与稳定性

- 主进程拆分为配置、IPC、窗口、浏览器、模型、技能、插件、工作区、记忆和恢复等模块，减少单文件耦合。
- 新增运行编排器和会话存储模块，统一任务准入、执行、恢复与终态处理。
- 内核事件接收增加独立 worker 和事件流处理，降低主线程阻塞对进度与终态的影响。
- 内核存储读取和删除进入独立子进程路径，减少数据库工作阻塞 Electron 主线程。
- 新增稳定性日志、事件统计和挂起检测；默认以观察和诊断为主。
- 修复后台任务隔离、任务结束状态、删除回收以及恢复提示的连接问题。
- 项目规则内容不变时不再把仅修改时间变化注入系统前缀，减少无意义的缓存前缀变动。
- 增加架构体积、IPC 清单和源码断言清单检查，并扩展上述功能的单元与 Electron 端到端测试。

## 18. 移除与迁移

- 移除实验性 AGI 模式及其专属自适应计算、推理旁路、长期规划、轨迹、工作流挖掘和相关实验代码；旧模式值迁移为常规模式。
- 移除 3D 工作岛／宫殿／观星界面及相关场景、贴图、音乐、Three.js 副本和构建脚本。
- 移除 Ghost Fibers 启动页、OGL 依赖及启动页专用构建步骤。
- 移除 Understand Anything 查看器和相关运行时／技能入口；现有 CodeGraph 与其他工程分析工具继续保留。
- 移除定时任务前端预览，包括导航、页面、脚本、样式及相关测试；旧调度配置继续清理，本版不提供定时任务执行功能。
- 清理 React Bits 技能入口及部分旧动画／设计技能副本；按当前技能和插件目录提供能力。
- 保留常规、计划和 Goal 等现有工作能力，不把它们列为本版首次新增；个性化设置统一控制记忆相关行为。
- 本机额外清理：Yan Agent 的 Rainmeter `YanClock` 皮肤已移入回收站并移除配置。它不是安装包组件，也不是对所有升级用户执行的系统清理。

## 验证与使用边界

- 本文列举代码变化，不承诺所有厂商／中转服务具有相同缓存命中率或生成速度。
- 插件账号、网络服务、模型额度及平台工具仍需用户自行具备；iOS／macOS 开发插件不会使 Windows 获得 Xcode。
- 外部桌面智能体的真实新建会话与复用路径要分别验证；已有实现文档明确区分离线回归与真实桌面验收。
