接入一次，沿用你的工作方式。

将终端的 API 地址指向 ViaHarness，设置 API Key，并使用虚拟模型 auto。本地代码、命令和工具仍由你的终端执行。

面向团队：统一供应商与成员额度，管理数据策略、模型权限和使用成本。

查看接入示例 Codex · 配置示意+

以下为配置示意。请将示例地址替换为实际服务地址，并在本地设置自己的密钥。

model = "auto"
model_provider = "harness"

[model_providers.harness]
name = "ViaHarness"
base_url = "https://api.example.com/v1"
wire_api = "responses"
env_key = "HARNESS_API_KEY"
在本地终端设置环境变量
export HARNESS_API_KEY="<你的 API Key>"

其他终端请使用各自支持的自定义模型服务配置方式。

在研究与真实世界之间，
构建下一层可能。

ViaTum Lab 是一家构建 Harness 中间层的前沿实验室。我们将算法研究、系统工程与产品实践连接起来，探索智能体如何跨任务、跨场景持续工作。

创始团队来自北京大学与清华大学，汇聚多名顶尖基础模型团队成员，团队孵化于国家重点实验室。

ViaHarness 是我们的多场景统一 Harness 基础设施，YAgent 是与其配套的开源客户端。两者连接智能选择、本地执行和结果审阅，形成从基础设施到用户工作区的完整产品结构。
