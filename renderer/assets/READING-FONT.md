# Bundled reading font

Noto Serif SC variable TrueType font, weight axis 200–900.
Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc
File: NotoSerifSC[wght].ttf (unmodified, stored as NotoSerifSC.ttf).
License: SIL Open Font License 1.1; see NotoSerifSC-OFL.txt.

Loaded locally as `Yan Reading Serif` with no `local()` lookup or network request.
The Electron build includes renderer/**/*, including the font and license.
The user's sans-serif setting and monospaced code styling remain separate.
