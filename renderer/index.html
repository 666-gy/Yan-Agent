视觉中继
让不支持读图的文本模型也能可靠理解图片和浏览器截图。

                
当主模型不能直接接收图像时，Yan 会把图片交给视觉模型读取，再把可核验的事实描述交回主模型继续工作。视觉中继只负责观察和转述，不执行用户任务；图片生成成功后不会自动重复读图。

  • 在“API 配置”中填写 GLM 或 Agnes 的 API Key；状态显示“已配置”后才会进入候选链路。
    • 
                  
  • 需要开启网络访问；读取本地图片或浏览器截图时，还需要允许文件读取。
    • 
                  
  • 每次中继会消耗对应厂商的 API 调用额度，Yan 不承诺任何模型永久免费。

遇到 429、5xx 或临时网络故障，Yan 会按上面的顺序自动切换；普通参数错误不会伪装成成功。

v1.4.0 完整更新

                  

                    
Yan Kernel（基于 OpenCode 二次开发）

                    
    
                      
  • 全新 Yan Kernel 成为唯一执行权威，统一处理事件流、权限、提问、错误收尾、上下文压缩与最终总结
    • 
                      
  • 新增 DeepSeek DSML 适配，协议片段不会泄露到用户正文；重复错误会熔断并给出可见原因
    • 
                      
  • 工作阶段与无工具最终总结分离，完成后可展开同一套正文 UI 查看工作过程
    • 
                    

                  

                  

                    
工作区与目标模式

                    
    
                      
  • Blank 可进行问答、浏览、应用操作、媒体生成和 Yan Skill 安装；用户文件写入必须先选择工作区
    • 
                      
  • 常规、计划、目标三种工作方式落地；目标模式只按原始要求定点验收和最小修复，最多 6 轮
    • 
                      
  • 工作区、任务和工具快照隔离；跨工作区/跨会话交接需要授权并复用目标工作区最近任务
    • 
                    

                  

                  

                    
Skill、MCP 与浏览器

                    
    
                      
  • Yan Skills、Yan Media、Yan Session、CodeGraph、Serena 和 Yan 内置浏览器按任务需要暴露
    • 
                      
  • Skill 的查找、安装、调用和删除锁定在 Yan 自己的 Skill 根目录；内置浏览器优先，Playwright 只作后备
    • 
                      
  • 内置浏览器按 ChatGPT 内置浏览器范式重做，支持专属标签页、完整交互操控、截图、显式等待、页面检查和交互证据
    • 
                      
  • Canvas/WebGL/3D 不再只看 DOM 或像素变化，Agent 控制状态会显示在页面和标签上
    • 
                    

                  

                  

                    
多模态与可靠交付

                    
    
                      
  • 主文本模型与图片/视频次模型共存，文件、视觉中继、媒体生成、编辑和上下文修改组成完整多模态链路
    • 
                      
  • 支持会话内媒体修改和 9 种图片比例；成功生成不会默认再次读图，图片/视频结果会进入最终输出
    • 
                      
  • 主模型不能读图时，可按 GLM 优先、Agnes 后备的视觉中继把截图事实转告主模型
    • 
                      
  • 审阅面板支持实时/持久化 diff、单文件打开、刷新恢复和回滚，并过滤图片、视频等二进制文件
    • 
                    

                  

                  

                    
记忆、设置与生态

                    
    
                      
  • 输入框上下文状态线实时同步模型、模式、预算和运行阶段；完成头部展示真实缓存 token 与命中率
    • 
                      
  • 新增模型感知的上下文压缩、长期记忆、缓存命中显示和跨会话有限交接
    • 
                      
  • 设置页加入视觉中继、最多 4 个用户口吻、快速启动（默认 Ctrl+Shift+Y）和移动端 LAN 指引
    • 
                      
  • 二代 Yan Agent Pet 实时同步当前任务、状态灯、工作阶段，支持拖动、展开、打开任务和结束任务
    • 
                      
  • 加入 Yan Prompt Optimizer，用户主动点击时只优化表达，不扩张原始任务
    • 
                      
  • 旧代码地图能力已进化为开箱即用的 Understand Anything；CodeGraph 作为其底层项目索引继续工作
    • 
                      
  • Yan Computer Use 正在开发，计划 v1.5.0 上线；Web UI 暂未更新，不建议使用；Yan Agent GUI 也计划 v1.5.0 上线

开启完全访问？

        
Agent 将不再为常规操作请求确认，并可使用绝对路径访问本机文件。仅在你完全信任当前任务、模型和工作区时开启。

        
你在设置中关闭的文件读写与网络权限仍然生效；高风险系统命令仍会被拦截。
