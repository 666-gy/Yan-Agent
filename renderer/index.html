重命名任务

        
        
        

          
          
        

      

    


    
    

      

        
删除任务？

        

        
删除后无法恢复该任务及其对话记录。

        

          
          
        

      

    


    
    

      

        
移除工作区？

        

        

          
          
        

        
仅从左侧任务列表移除，不会删除本机文件或任务记录。

        

          
          
        

      

    


    
    

      

        
删除 Skill？

        

        
删除后 Agent 将无法继续调用它，需要重新安装才能恢复。

        

          
          
        

      

    


    
    

      

        
开启完全访问？

        
Agent 将不再为常规操作请求确认，并可使用绝对路径访问本机文件。仅在你完全信任当前任务、模型和工作区时开启。

        
你在设置中关闭的文件读写与网络权限仍然生效；高风险系统命令仍会被拦截。
