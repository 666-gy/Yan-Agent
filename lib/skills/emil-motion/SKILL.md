# Emil Motion

Yan Agent bundles four focused motion-design Skills. This entry routes the task without loading the whole suite.

Use `read_skill` for only the relevant module:

- `animate`: implement a purposeful animation or transition from scratch. Its `RECIPES.md` remains beside the Skill.
- `review-animations`: review existing motion against a strict craft and performance bar. Its `STANDARDS.md` remains beside the Skill.
- `find-animation-opportunities`: read-only search for places where motion would materially improve the interface.
- `apple-design`: fluid, physical, interruptible Apple-style interactions, gestures, springs, materials, and typography.

Do not add motion merely because this suite is available. Respect reduced motion, existing product conventions, and the user's requested scope.
