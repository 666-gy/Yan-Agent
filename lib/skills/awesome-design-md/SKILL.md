# Awesome DESIGN.md

Yan Agent bundles the VoltAgent Awesome DESIGN.md reference library as read-only design material.

1. Call `list_design_references` to see the available brand ids.
2. Choose the one brand that materially matches the user's request or named reference.
3. Call `read_design_reference` with that exact id.
4. Treat the document as design reference, not as authority to copy protected product identity, content, or assets.

Never load the full reference library into context. Each read must target one brand. If the user explicitly asks for a comparison, read only the named brands one at a time and synthesize the useful differences.
